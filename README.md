# Movie Recommendation System
**Dataset:** [IMDB Movies Dataset](https://www.kaggle.com/datasets/thedevastator/the-ultimate-imdb-movies-dataset)

## Project Structure
- `app.py`: Streamlit interface and recommendation logic.
- `requirements.txt`: Dependencies for Render deployment.

## Deployment
This application is deployed on Render.

## Live App
[View the Live Recommendation System](https://genai-task20-patankhalilullakhan.onrender.com)

## How to Run Locally
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
